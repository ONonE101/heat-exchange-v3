# Устройство приложения

## Поток данных

Браузер отправляет форму в `CalculatorController`. MVC связывает поля с `HeatExchangeInput`,
проверяет обязательные значения, диапазоны и токен защиты формы. Валидные параметры передаются
в `HeatExchangeCalculator`. Контроллер передаёт результат в Razor-представление;
таблица и SVG-графики используют один и тот же набор точек.

## Основные файлы

| Файл | Назначение |
| --- | --- |
| `Models/HeatExchangeInput.cs` | Параметры варианта 3 и правила проверки |
| `Services/HeatExchangeCalculator.cs` | Аналитическое решение и тепловой баланс |
| `Services/CalculationRepository.cs` | Постоянное файловое хранилище |
| `Controllers/CalculatorController.cs` | Расчёт, сохранение, загрузка, удаление и CSV |
| `Infrastructure/FlexibleDoubleBinder.cs` | Разбор десятичной точки и запятой |
| `Views/Calculator/Index.cshtml` | Форма и результаты |
| `Views/Shared/_Chart.cshtml` | SVG-диаграммы с координатами и подсказками |
| `Views/Calculator/Saved.cshtml` | Список вариантов |

## Численная устойчивость

Тепловая мощность вычисляется по эффективности противоточного теплообменника.
Для Cᵣ = 1 используется точный предел ε = NTU / (1 + NTU).
Функция exp(x) − 1 при малом аргументе вычисляется через разложение в ряд.
Температурные профили строятся от той границы, для которой показатель экспоненты неположителен.
Поэтому при m > 1 не возникает переполнения положительной экспоненты.
Формулы эквивалентны решению системы балансов для термически тонких частиц.

## Маршруты

| Метод и путь | Действие |
| --- | --- |
| `GET /` | Базовый вариант |
| `POST /calculate` | Расчёт введённых параметров |
| `POST /save` | Новое сохранение |
| `GET /?load=<GUID>` | Открытие сохранённого снимка |
| `GET /calculations` | Список вариантов |
| `POST /calculations/<GUID>/delete` | Удаление варианта |
| `POST /export` | CSV текущего расчёта |
| `GET /calculations/<GUID>/csv` | CSV сохранённого расчёта |

Все изменяющие POST-запросы защищены `AutoValidateAntiforgeryToken`.
Имена выводятся средствами Razor с HTML-кодированием; файловые имена формируются из GUID.
