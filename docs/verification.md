# Проверка приложения

Дата проверки: 5 ноября 2026 года.

## Автоматические тесты

`dotnet test HeatExchange.slnx`: 18 пройдено, 0 ошибок, 0 пропусков.

Проверены совпадение с предыдущим расчётом в Excel, контрольный пример методички,
режим равных теплоёмкостей потоков, конечность температур при крайних параметрах,
граничные условия, нагрев и отсутствие теплообмена, запрет недопустимых расходов.
Отдельно проверены сохранение и повторное чтение, 10 конкурентных записей,
изолированное удаление и запрет пустого названия.

## Браузерные проверки

Google Chrome, настольное окно 1440 × 1100 и мобильное 390 × 844:

- Результат базового варианта — 20,43 °C и 464,98 °C.
- Таблица содержит 51 точку; отображаются оба графика.
- При w = 0,624 м/с температура окатышей составляет 24,64 °C.
- Поддерживаются точка и запятая в форме.
- Вариант сохраняется, присутствует в списке и повторно открывается.
- Нулевой расход отклоняется, ошибочный результат не показывается.
- На мобильном экране страница не имеет горизонтального переполнения;
  широкая таблица прокручивается внутри своей области.
- Ошибок JavaScript не обнаружено.

## HTTP-проверки

- CSV имеет UTF-8 BOM, 4 колонки и 51 строку результатов, последняя температура совпадает с расчётом.
- POST без токена защиты формы возвращает HTTP 400.
- NaN и отсутствующий обязательный параметр отклоняются.
- HTML в названии варианта кодируется при выводе.
- Удаление работает; открытие удалённого варианта возвращает HTTP 404.

## Практический предел проверки

Проверены локальный запуск и публикационная сборка. Развёртывание на внешнем сервере не выполнялось.
