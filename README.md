# Теплообмен в противотоке

Учебное веб-приложение для варианта 3 по дисциплине «Моделирование процессов и систем в металлургии».

Стек: C#, ASP.NET Core MVC, .NET 10. Автор: Шарапов Демьян С., НМТ-343901.

## Запуск

Требуется .NET SDK 10. Откройте папку проекта и выполните:

```sh
dotnet run --project HeatExchange.Web --urls http://localhost:5183
```

Откройте http://localhost:5183 в браузере.
