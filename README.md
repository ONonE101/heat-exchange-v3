# Теплообмен в противотоке

Учебное веб-приложение для варианта 3 по дисциплине «Моделирование процессов и систем в металлургии».

Стек: C#, ASP.NET Core MVC, .NET 10. Автор: Шарапов Демьян С., НМТ-343901.
Преподаватель: Гурин И. А.

## Запуск

Требуется .NET SDK 10. Откройте папку проекта и выполните:

```sh
dotnet run --project HeatExchange.Web --urls http://localhost:5183
```

Откройте http://localhost:5183 в браузере.

Также можно открыть `HeatExchange.slnx` в Visual Studio с поддержкой .NET 10 или запустить `Start.cmd`.

## Возможности

- Редактирование исходных данных; по умолчанию используется вариант 3.
- Серверная валидация диапазонов и конечности чисел. Для дробей принимаются точка и запятая.
- Таблица температур в 51 точке при базовой сетке. Можно выбрать от 10 до 500 интервалов.
- Два SVG-графика: температуры материала и воздуха, разность температур.
- Сохранение, открытие и удаление именованных вариантов. Сохранение всегда создаёт новый вариант.
- Выгрузка CSV с разделителем `;`, UTF-8 BOM и десятичной запятой для Excel.

## Базовые данные и результат

H = 5 м, t₀ = 700 °C, Tᵢₙ = 20 °C, w = 0,78 м/с, cг = 1,32 кДж/(м³·К),
G = 1,72 кг/с, cм = 1,49 кДж/(кг·К), αᵥ = 2460 Вт/(м³·К), D = 2,2 м.

Температура окатышей на выходе — 20,4324926422 °C, воздуха — 464,9831272957 °C.
Тепловая мощность — 1741,5956078566 кВт.

Координата y отсчитывается от верха слоя вниз; материал движется вниз, воздух — вверх.
Модель предполагает стационарность, постоянные свойства, термически тонкие окатыши и отсутствие потерь теплоты.

## Хранение данных

Варианты записываются в `HeatExchange.Web/App_Data/Calculations/<GUID>.json`.
В файле хранятся название, UTC-время создания, исходные параметры, все результаты и версия модели.
Запись сначала выполняется во временный файл, затем файл атомарно переименовывается.
Операции записи синхронизированы внутри процесса. Для учебного локального запуска база данных не нужна.

Папка `App_Data` исключена из Git и из архива исходного кода. Не удаляйте её при обновлении, если хотите сохранить свои варианты.
Другую папку можно задать через переменную среды `Storage__Directory`.
Приложение рассчитано на локальное использование; варианты общие для посетителей одного экземпляра приложения.

## Проверка

```sh
dotnet test HeatExchange.slnx
dotnet publish HeatExchange.Web -c Release -o artifacts/publish
```

В проекте 18 тестов xUnit: базовый вариант, контрольный пример, равные теплоёмкости потоков,
крайние параметры, отсутствие теплообмена, нагрев, отклонение неверных данных,
сохранение после повторного создания хранилища, конкурентная запись и удаление.
Дополнительно выполнены браузерные и HTTP-проверки; см. `docs/verification.md`.

## История работы

Отдельные этапы зафиксированы отдельными коммитами. Посмотреть историю:

```sh
git log --oneline --reverse
```

